# 🛍️ E-Commerce Store

A modern and responsive e-commerce web application built with **React**, **Redux Toolkit**, and **Material UI**.

The project focuses on building a complete shopping experience, from browsing products to managing a wishlist and cart, completing checkout, and receiving an order confirmation.

---

## 🔗 Links

- Live Demo: https://nexora-shop-app.netlify.app/
- GitHub Repository: https://github.com/Yusuf-Mohamed-1/ecommerce-store

---

## ✨ Features

### 🛒 Shopping Experience

- Browse products with pagination
- Search and filter products
- Sort products
- View detailed product information
- Add and remove products from the cart
- Update product quantities
- Automatic subtotal and total calculation
- Free shipping for orders over $100

### ❤️ Wishlist

- Add products to the wishlist
- Remove products from the wishlist
- View all saved products
- Wishlist state synchronized with product cards

### 💳 Checkout

- Checkout form with validation
- Input error handling
- Order summary
- Shipping calculation
- Order confirmation page
- Automatically clears the cart after a successful order

### 🎨 UI & UX

- Responsive design for desktop and mobile
- Mobile-friendly shopping experience
- Dark mode
- Loading states
- Error handling
- Empty cart and empty wishlist states
- Reusable UI components

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Yusuf-Mohamed-1/ecommerce-store.git
```

### 2. Navigate to the project

```bash
cd Nexora-Store
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available through the local Vite development server.
